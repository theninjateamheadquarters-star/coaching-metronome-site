Chrome extension

Coaching Metronome

A box-breathing metronome designed for coaching sessions – with smooth visuals, simple controls, and a clean unlock.

How to use it

  • Install the Coaching Metronome Chrome extension.
  • Click the extension icon to open the metronome.
  • Set your session length and phase time.
  • Click Buy inside the extension to unlock premium.

After purchase, you’ll receive a license code and can unlock the extension from the lock screen using your email and code.
